# Documentation Index

This directory contains the engineering documentation baseline for `Journal Club Asia / Okkhor`.

## Sections

- `architecture/` - system design, boundaries, flows, and context
- `adr/` - Architecture Decision Records and ADR templates
- `runbooks/` - operational procedures, postmortems, and incident guidance
- `standards/` - engineering process standards and supporting practices

## Usage Rule

When a technical decision, incident workflow, or operational pattern becomes repeatable, it must be documented here instead of remaining only in chat or memory.
